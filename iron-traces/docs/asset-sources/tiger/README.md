public/audio/foley/tiger-engine.ogg uses seconds 95–102 after the engine starts, with 55 Hz high-pass, 3200 Hz low-pass, mild compression, 200 ms wrap crossfade and peak normalization to 0.85. Duration: 6.8 seconds; mono Vorbis quality 6.

This is a restored Tiger 131 engine recording, not a wartime recording or separate recordings of every German vehicle variant. All enemy vehicles currently share this Tiger-derived loop. Driving RPM is adapted with playback speed; this does not recreate a separately recorded acceleration sequence. Player engines retain the independent Sherman recording. Both use the existing positional, distance and obstruction processing.
