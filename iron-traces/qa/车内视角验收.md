# 车内炮手视角验收

2026-09-10，本地生产构建更新。新增第三视角，不修改原战役规则。

## 实现

- C 在俯视、过肩、车内之间循环；车内镜头置于本车内并跟随实际炮塔，不以外部跟随镜头冒充第一人称。
- 独立三维舱内绘制：厚装甲观察框、手轮、炮闩、仪表和铭牌。观察框遮挡大部分画面；本车外部模型在该视角隐藏。不同窗口比例调整零件位置，保持轮形和仪表形状。
- 固定瞄准标尺；鼠标偏离中央停止区控制左右转动，R 以原有炮塔速度回正。旋转输入在固定模拟步长内计算，避免依赖显示帧率。
- 小地图、外部瞄准提示与目标地面光环隐藏；M 展开地图也不显示任何敌车或残骸标记。原来两种视角仍显示原地图信息。
- 舱内低通声音、发动机低频加强、开炮炮闩后坐及轻微行驶震动。当前内构为程序生成的游戏近似，没有声称历史级内构、光学或声学复原。

## 验证

- TypeScript / Vite 构建通过；16 项测试通过，包括新增的三视角循环、信息策略、炮塔中央停止区与实际炮弹朝向测试。
- 真实页面键鼠：鼠标向右移动后炮塔由 3.1416 转至约 2.7879 弧度；鼠标回中后两次间隔读取方向相同；R 回正有效。
- 车内左键射击扣除一发 HE：22 → 21，装填倒计时正常。
- 车内按住 W 后位置 z 从 34 变为约 29.51；Esc 暂停期间模拟时间冻结。
- 地图像素检查：相同任务的外部大地图包含 2417 个精确敌军标记色像素；车内地图为 0。切出车内后显示策略恢复为允许敌车标记。像素检查产生的 Canvas2D 读回优化提示来自测试读取，不属于运行错误。
- 车内连续三次重试：均为 115 个已上传几何资源、17 个纹理，没有持续增长。三次视角循环也未增加资源。
- 1440 × 900 与 800 × 900 截图检查，车内观察口与必要操作可见。最终控制台 0 错误、0 警告。
- 车内暖机后的短时帧间隔中位数约 16.7 ms；此项不代替长期、多设备压力测试。
