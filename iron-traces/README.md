## 教育型作战简报

首页采用左地图、右战车与任务资料、下方完整战史的纸质档案布局。当前唯一可玩的诺曼底简报正文共 1048 个汉字（不含标题和来源），包含五个章节，支持滚轮、键盘、章节跳转和可暂停的自动滚动。手动操作自动停止滚动。每条战役数据均由测试校验正文至少 500 个汉字；未来增加战役须满足相同约束。真实历史引用公开史料，本局地图、车组与任务单独说明为游戏改编。

## 高画质档

右上角画质按钮按标准→高→流畅循环，选择保存在当前浏览器。高档最高 2560×1440 渲染（按屏幕比例缩放，最高 2 倍像素比）、4096² 阴影，持续烟火间隔 65ms；标准 1920×1080 上限、2048² 阴影、100ms 烟火；流畅降低分辨率、关闭太阳阴影、200ms 烟火。实际分辨率依窗口尺寸，画质档不改变坦克模型几何。

## 战场反馈与素材更新（2026-09-10）

- 命中位置闪光、金属火花；击毁产生火球、烟团和短暂环境照明。
- 血量低于约 70% 开始冒烟，低于约 35% 起火，残骸焦黑并持续燃烧；残骸火焰约 65 秒后停止，烟最多持续 120 秒。维修后停止新增损伤烟火，已产生的烟自然消散。这是游戏化视觉阶段，不是引擎/燃油物理损伤模型。
- 360 粒子硬上限、一次批量绘制，最多 4 个瞬时照明和 2 个持续火光；暂停冻结视觉效果，重开清理。
- 简报与整备各使用一张内置 image_gen 生成的插画，原 PNG 和轻量 WebP 均保留在 public/images。提示词见 docs/asset-sources/images.md。
- 7 个音频文件：3 种真实靶场炮声切片、引擎循环、燃烧、爆炸、金属撞击。来源、作者、许可及剪辑说明在 public/audio/CREDITS.md，简报页可直接访问。
- HRTF 耳机方向音效：监听位置在本车，方向取当前摄像机水平朝向；敌方引擎与燃烧声实时移动，炮声发生在炮口位置。距离衰减、建筑/树林/砖墙遮挡滤波、车内低通与动态压缩。暂停菜单可测试“先左后右”。
- 录音失败时使用备用噪声并提示；并非全部二战车型原车实录，没有虚构步兵脚步声。

旧章节中的音效合成与简报实时镜头说明，已由本节更新替代。

# 铁迹 · 诺曼底 1944

首个可玩战场，基于 Three.js + TypeScript + Vite。范围对应完整设计计划的落地附录：96 米方形地图、一辆谢尔曼、三辆敌车及完整任务循环。

## 启动

需要 Node.js 20.19+ 和支持 WebGL 2 的桌面浏览器。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:8874/ 。点击“进入战场”后声音启动。若自动暂停，点击继续。

可移交的静态版本：`npm run build`；运行 `npm run preview`，或用任意静态 HTTP 服务托管 `dist/`。所有游戏资源均在本地生成或打包，不依赖 CDN、远程模型、字体或账号。不能直接双击 HTML 文件运行模块。

## 操作

| 操作 | 按键 |
|---|---|
| 前进 / 倒车 | W / S |
| 车体向左 / 右转 | A / D |
| 瞄准 / 开火 | 鼠标移动 / 左键（可按住连射） |
| 穿甲 / 高爆 | 1 / 2 |
| 俯视 / 过肩 / 车内循环切换 | C |
| 车内炮塔回正 | R |
| 暂停 / 恢复 | Esc |
| 暂停并查看地图 | M |
| 补给 | 出发点东侧停车，按住 E 八秒 |

高爆弹两发打掉一个墙段；穿甲弹需要五发。墙体阻止当前炮弹，下一发才能通过缺口。密林与建筑不能穿过。沼泽按四个履带接触点混合减速，完全进入后前进与转向均为普通地面的 45%。左右履带轨迹来自实际位移和转动。

击毁三辆敌车后，前往北侧星标路口停车五秒获胜。不要直接冲进交叉火力；利用剩余墙体遮挡，及时选择穿甲弹，必要时倒车撤回补给点。补给点每局可用两次，每次最多补充十二发并恢复 35 点车体耐久。

首次胜利后，在“战车整备”中选择穿甲或高爆装填优化，对应装填时间从 5.2 秒缩短至 4.8 秒。是玩法整备抽象，未改变历史口径或单发伤害。解锁只存当前浏览器；不使用云账号。

## 新增：车内炮手视角

从默认俯视按两次 C 进入。装甲观察框遮挡大部分外部视野，可见舱内手轮、炮闩、仪表和固定瞄准标尺。镜头在本车内部，朝向跟随实际炮塔，而非独立的观察摄像机。

车内使用缓慢转动控制：鼠标移向画面左右两侧转动炮塔，回到中央停止区即停转；R 让炮塔以正常转速回到车体正前方。W/S/A/D、左键射击、1/2 换弹、E 补给仍然有效。点击界面按钮不会让炮塔自行转动。

车内隐藏小地图、外部瞄准点和任务地面光环。M 展开地图时仍可查看道路、树林、目标和补给，但不显示任何敌车或残骸标记；C 切回外部视角后恢复原显示。暂停和重试同样有效。

车内对声音施加平滑低通并加强发动机低频，炮闩随本车开火后坐，行驶时有很轻的舱内振动。视角采用程序生成的炮手观察位近似模型，并非扫描还原的谢尔曼内构、完整光学系统或穿透物理；不将氛围提升称作历史级仿真。

## 已完成与后续边界

本版本包含简报、车型与部队说明、可破坏墙、沼泽、密林、敌车绕障、三种视角、主炮与装填、补给、胜负重开、战果升级、小地图及声音开关。普通画质渲染上限为 1920 × 1080，流畅档降低分辨率并关闭太阳投影。

这是可玩切片，尚非完整六局成品。坦克与环境是程序生成的近似模型；原计划中的 GLB 精细资产、其余五局、雪地材质、逐战役天气与更丰富的敌军战术仍在后续阶段。履带印痕用固定 2048² 地表纹理与凹凸光照表现，缓慢淡化；尚非分块逐条寿命管理或真实泥土形变。坦克不模拟逐节履带刚体。音效为 Web Audio 程序合成，尚非经历史校核的录音。未实现完整音频遮挡模型。战场与车组虚构，比例压缩，非真实战役的逐米复原。

资源未使用 AI 概念画面充当实时画面。游戏里看到的三维场景都可以驾驶进入。

## 验证与代码

```sh
npm test
npm run build
npx prettier --check src tests vite.config.ts tsconfig.json package.json index.html
```

- `src/simulation.ts`：独立于渲染的 60 Hz 固定步长规则、连续弹道碰撞、旋转车体碰撞、网格绕障。
- `src/world.ts`：程序模型、合并绘制、地表印痕、双相机与有限特效池。
- `src/audio.ts`：程序发动机、地面阻力声、主炮、命中、补给提示。
- `src/main.ts`：中文界面、键鼠输入、地图、暂停、结果与浏览器本地解锁。
- `tests/simulation.test.ts`：规则与边界回归测试；另有 `tests/view.test.ts` 的视角策略测试，共 16 项。
- `qa/验收记录.md`：本轮实测、审查修复与未覆盖范围。

`window.__ironTraces.inspect()` 提供只读诊断快照。状态注入与加速检查仅在 Vite 开发模式存在，生产构建不包含这些入口。
